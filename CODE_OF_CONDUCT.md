# Code of conduct

This is a one-person project about a climate card. It does not need a long
document, but it does need the rules written down before anyone has to invoke
them.

## What is expected

- **Assume the other person is trying.** A bug report with no version number
  and a pull request that ignores the conventions are both someone spending
  their evening on this. Ask for what is missing.
- **Keep it about the card.** Its behaviour, its code, its documentation, and
  what a device does or does not report.
- **English**, so that everyone in a thread can follow it. See
  [CONTRIBUTING.md](CONTRIBUTING.md).

## What is not acceptable

Harassment of any kind; personal attacks and insults; comments about someone's
identity - who they are, where they are from, what they believe, how they
speak; unwanted attention after being asked to stop; publishing anyone's
private information; and posting or linking anything that would make a
reasonable person close the tab.

None of this becomes acceptable by being phrased as a joke, as bluntness, or as
technical criticism.

## Where this applies

Everywhere this project lives on GitHub: issues, pull requests, code review,
commit messages, and the repository's own pages.

## How it is enforced

The maintainer moderates. In practice that means hiding a comment, locking a
thread, closing an issue, rejecting a contribution, or blocking an account -
whichever fits, and without a warning first when the behaviour is bad enough.

**There is no private mailbox to report to, and this document is not going to
invent one.** A single-maintainer project cannot offer a confidential channel
that leads anywhere except back to the maintainer, and pretending otherwise is
worse than saying so. What exists instead:

- **Something in a thread needs attention** - say so in the thread, or open an
  issue. Both are read.
- **The maintainer is the problem, or the behaviour breaks GitHub's own rules** -
  report it to GitHub through
  [their abuse form](https://github.com/contact/report-abuse). That route does
  not pass through this repository and is not visible to the maintainer, which
  is exactly the point.

GitHub's own
[Community Guidelines](https://docs.github.com/site-policy/github-terms/github-community-guidelines)
apply here on top of everything above, and they are enforceable by GitHub
whatever this file says.
